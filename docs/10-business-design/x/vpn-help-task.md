## 要点
- 表(schema 1.2.40):`x_vpn_post`(一条求助帖一行,id = 推文 id)、`x_vpn_reply`(回复一次一行,也是「回复求助」的范例库,和求关 / 互动分开);点评 / 放一放的 mode 加了 vpn。
- ⚠️ 登记前先看这条**自己**命中配方没有(关键词任一 且 求助信号任一,`matchesRecipe`)—— 搜索载荷里带着被引用 / 上文的推文(真机第一轮混进 10 条无关的)。
- 判断提示词取自 9-29 删掉的 `x-ai-judge.ts`(双向产品、worth 分类);例子取 tweet_feedback(约 6900 条人工标注)。判不出 → judge_error 下次重判,**绝不当成「不值得」**。
- 回复:只用 `PRODUCT_FACTS`;链接 = `situstechnologies.com/x?ref=tw_<号>_<日期>_<配方>&lang=..`(能按配方对账转化);`verifyGeneratedReply` 校验(链接逐字 / 没带 / @ / 太长 / 最高级)+ 不带话题标签;外语回译中文。
- 回复卡上「跳过此人」换成「不值得回」—— 排除一个人会让他在蓝V任务里也消失。
