## 5. 环境坑(踩过,会再遇到)

**真机跑 Electron 前先清 `ELECTRON_RUN_AS_NODE`**:

```bash
env -u ELECTRON_RUN_AS_NODE <你的命令>
```

否则 `require('electron')` 命中 npm launcher 包,报 `Cannot find module 'electron'`
—— **与「Electron 装坏了」一模一样,极易误判**(有人为此失败 5 次)。
