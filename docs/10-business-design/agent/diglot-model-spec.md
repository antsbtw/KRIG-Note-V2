# Diglot 模型规格 v0.2 — 语义描述 / 图形描述（mind）

> 本文档定义 mind 图种的完整模型：实体、属性、分层归属、推导规则、落位规则、规范化纪律、交互投影与不变量。图形能力的参照系为 **XMind 单一基准**。它是各投影（平文本 DSL、KRIG block、left/right slot 界面）共同的真相来源；Phase 0 的全部断言由本文档导出。

---

## 1. 总则：两层一体，双射唯一

每份 mind 文档由两层描述构成，合起来完备地决定一张图：

**语义描述（S 层）** —— 图"是什么"：节点、层级、内容、关系、标注。用户书写的，机器不改写（增量锚定序列化，保注释、保书写顺序、保个性）。

**图形描述（G 层）** —— 图"长什么样"：坐标、布局结构、样式、折叠。**用户可写，机器规范**：G 层拥有自己的一等书写面（§7），用户可以直接手写属性；机器保留规范化的权力——每次编辑落定后重整为规范形（排序、canonical 键名、量化、剔缺省）。**稀疏纪律**：缺省即自动（default = auto），只有被触碰过的元素才存在条目；删除条目即释放回自动。

其中一小类 G 属性标记为**视图属性（V 类）**：不改变内容也不改变排版语义，只记录"此刻怎么看"（如折叠状态），逐个决定是否随文档持久。

**双射承诺**：文档 ⇄ 图形唯一确定。同一张图无论经何种编辑路径到达，其 G 层规范形字节级一致；S 层固定为用户自己的书写代表元。

**附录区是投影的产物，不是模型的部件**：模型中只有"实体 + 属性"。平文本投影把 G 层落成文末 `<!-- diglot … -->` 附录；KRIG 投影把 G 层存为属性三元组，并以图形描述面呈现（§7）。

## 2. 实体清单

模型共四种实体：**Node（节点）**、**Edge（联系线）**、**Span（区间引用：概要/边界）**、**Document（文档）**。外部引用不是独立实体，是 Node 的一种内容形态。

### 2.1 Node（节点）

| 属性 | 层 | 类型 | 缺省 | 说明 |
|---|---|---|---|---|
| `id` | S | 稳定标识 | 自动分配 | 两层之间的外键，选区同步的 join 键。KRIG = block id（即 SurrealDB 实体 id / Atom 挂靠点）；平文本 = `^id`，未显式书写者由系统分配人类可读 id 并管理 |
| `content` | S | 富文本 | —（必填） | 节点内容。**首段为节点标签**（图上显示），**其余为备注**（XMind notes 对应物，图上以备注标记呈现）。KRIG 中 content 即 note block 本体，公式、行内格式、图片、超链接天然承载——XMind 需专门机制的富内容整类白送 |
| `parent` | S（推导） | Node 引用 | 按 §3 推导 | **真相是父子关系，不是层级数字**。层级（h1~hn / 缩进）是书写表面，parent 是解释结果 |
| `order` | S（推导） | 整数 | 书写顺序 | 兄弟间次序 |
| `role` | S（推导） | `root \| branch \| floating` | `branch` | root = 文档标题；顶层节点缺省为主分支；标 `float` 者为自由主题（父为 Document，游离于 root） |
| `ref` | S | 不透明字符串 | 无 | 外部引用节点：content 为 `[[ref]]` 时指向另一文档/块，Diglot 渲染占位并透传，宿主解析。嵌套（zoom-in / XMind 钻取）与跨文档组合由此实现 |
| `labels` | S | 字符串集 | 空 | 自由文本标注（XMind label）：钉在节点上的小字标签 |
| `markers` | S | 词表项集 | 空 | 受控标记（XMind marker）：优先级 1–5、进度、旗帜、表情等**枚举词表**，可排序可比较可过滤。与 labels 分设——合并会丢掉枚举语义。KRIG 中为三元组："全库高优先级节点"是一句查询 |
| `shape` | G | 词表项 | `auto` | 形状。词表开放可注册，中英别名互通，存储用 canonical 名 |
| `color` | G | 词表项/色值 | `auto`（主题决定） | v0 样式最小集只收 color；线型、字体等经词表注册机制扩展 |
| `pos` | G | `(x, y)` 整数 | 无（= auto 布局） | **pos 存在即 pinned**：写入即钉住，删除即释放。量化为整数 |
| `structure` | G | 词表项 + 参数 | `inherit`（根缺省 `map`） | 该节点子树的布局算法，可挂任意节点、向下继承（XMind 分支级结构混用）。词表按 XMind 十结构全集登记：`map`（顺/逆时针参数）、`logic`（左右向）、`brace`、`org`（上下向）、`tree`、`timeline`、`fishbone`（左右头）、`tree-table`、`matrix`；方向变体为参数（`structure=fishbone dir=left`）而非独立词条。**v0 实现 `map` 与 `logic`**，其余登记名称、布局算法后续实现 |
| `collapsed` | G（V 类） | 布尔 | `false` | 折叠状态，**持久**。折叠是属性不是类型：一切节点天然可折叠 |

### 2.2 Edge（联系线）

任意两节点间的非树连线（XMind relationship）。**两端强制显式 id**——显式 id 的激励设计：想连线，先命名。

| 属性 | 层 | 类型 | 缺省 | 说明 |
|---|---|---|---|---|
| `source` / `target` | S | Node id | —（必填） | 模型统一存有向；无向语义由渲染弱化箭头表达 |
| `label` | S | 字符串 | 空 | 关系标签 |
| `id` | S | 稳定标识 | 自动 | 可显式命名以便外部挂靠 |
| `waypoints` | G | 点列 | `auto` | 手动走线，稀疏纪律同 pos |
| `style` | G | 词表项 | `auto` | 线型/色 |

KRIG 投影：`relates(source, target) {label}` 三元组——联系线直接就是图谱边，天然可查询。

### 2.3 Span（区间引用：概要 / 边界）

对**一段连续兄弟节点**的引用实体。XMind summary 与 boundary 的共同本质，也是 KRIG "框选一段 blocks 建立关系" Canvas 原语的先声。

| 属性 | 层 | 类型 | 缺省 | 说明 |
|---|---|---|---|---|
| `kind` | S | `summary \| boundary` | — | 概要 = 框住并挂结论；边界 = 仅框住 |
| `from` / `to` | S | Node id | —（必填） | 同父连续兄弟段的首末锚点。锚在 id 上，节点移动/更名不破坏区间 |
| `topic` | S | Node 引用 | kind=summary 时必有 | 概要的结论节点：本身是 Node，父挂 Span |
| `style` | G | 词表项 | `auto` | 框线样式 |

书写入口：summary 有语义面入口（`/sum` 手势）；boundary v0 仅画布入口——依据收录门槛"有人会用文字手写它"。

### 2.4 Document（文档）

| 属性 | 层 | 类型 | 缺省 | 说明 |
|---|---|---|---|---|
| `type` | S | `mind` | — | 文档类型 = 解释器选择，标于 Note 元数据（侧栏图标区分）。同一 blocks 数据可按大纲或导图解释，切换零转换 |
| `title` | S | 富文本 | — | **标题即 root**：Note 标题为中心主题；平文本投影为首个零缩进行 |
| `theme` | G | 词表项 | `auto` | 全局主题/配色 |

**Sheet 对应**（XMind 用户迁移锚点）：多 sheet = 多个 mind Note；**"从主题新建 sheet" = 子树摘出为新 Note、原位留 `[[ref]]`**——block 架构"任意块提升为独立文档"的既有操作，零新机制。

## 3. 树推导规则（书写表面 → 父子真相）

输入是**扁平序列**：KRIG 投影为"带 h 级别的 block 序列"，平文本投影为"带缩进的行序列"。两者同构，推导规则唯一：

1. `parent(n)` = 序列中 n 之前、级别小于 n 的**最近**节点；不存在则父为 root。
2. **级别跳跃宽容解释**：h1 下直接出现 h3，按规则 1 归就近父级，不报错、不改写用户书写。
3. `order` = 同父兄弟间的序列先后。
4. 标 `float` 的顶层节点父为 Document（自由主题）。
5. 推导是确定的纯函数：同一序列必得同一棵树（断言 A1）。

**层级数字永不落库**。移动子树 = 改一条 parent 引用 / 平移缩进块，后代无需重编号。`/h1…/hn` 与 Tab/Shift-Tab 是升降级**手势**，落成的是父子关系变更。

## 4. 所有权与落位规则

**S 面（语义描述）：纯语义，机器不动。** 增量锚定序列化，保注释、保顺序、保个性。语义面中键入的斜杠词（`/三角形`、`/float`、`/sum`、`/h2`）一律是**输入手势**：落定后转化为对应的属性条目（归 G 面）或结构变更（父子关系、Span 创建），语义面本身不留属性 token——语义面百分之百为语义服务，与 `/h1` 不在 block 上贴层级数字是同一先例。

**G 面（图形描述）：用户可写，机器规范。** 用户可直接手写与编辑属性条目（`^arch color=red pos=420,180`）；每次编辑落定后机器重整为规范形（§5），体验类比 `terraform fmt`：随手写，松手变整齐。坏行不污染模型、行内标红（A7 延伸）。配 id 与键名自动补全，G 面即高级用户的批量操作面板。

**画布：操作分流落笔。** 结构操作（新建、连线、删除、改名、升降级）落 S 面（锚定增量写入）；布局与样式操作（拖动、改色、折叠、框边界）落 G 面（规范条目）。

**删除即缺省**：删去 G 面条目 = 该属性回到 auto（释放回自动布局获得文本表达，断言 A8）。

---

## 5. 规范化纪律（G 层规范形）

- 条目按 `id` 字典序排列；条目内属性键按固定序（canonical 键名，英文）；
- 坐标量化为整数，杜绝浮点噪声；
- **不写缺省值**（稀疏纪律：缺席即 auto）；
- 词表值存 canonical 名（中英别名在输入层互通）；
- 规范化幂等：对规范形再序列化，字节级不变（断言 A2）。

平文本投影中 G 层落于文末附录区，包裹于 HTML 注释，使文件在任何 Markdown 环境渲染为干净大纲：

```
<!-- diglot
^arch pos=420,180
^root structure=logic
^todo float pos=-200,60 collapsed
-->
```

## 6. 投影对照表

| 模型概念 | 平文本 DSL | KRIG block |
|---|---|---|
| Document.title / root | 首个零缩进行 | Note 标题 |
| 层级 | 缩进 | h1~hn 序列（Tab/`/hn` 为手势） |
| Node.id | `^id`（可选显式） | block id（天然存在） |
| 标签 + 备注 | 内容行 + `>` 引用行 | block 内容首段 + 余部 |
| 自由主题 | 后续零缩进行 | 顶层 block 经手势标 float |
| 联系线 | `^a -> ^b 标签`（关系行，惯例收于树后） | `relates` 三元组 |
| 概要 | `/sum` 手势生成结论节点 | Span 实体 + 结论 block |
| 边界 | 仅 G 层 | Span 实体（画布生成） |
| 外部引用 / 钻取 | `[[ref]]` | block 引用 + 惰性展开（既有机制） |
| 多 sheet / 从主题新建 sheet | 多文件 | 多 Note / 子树摘出 + 原位 `[[ref]]` |
| G 层 | 文末 `<!-- diglot -->` 附录 | 属性三元组 + 图形描述面 |

Mermaid mindmap 兼容为顺手即收的低成本特性（缩进文法天然相近），不再是模型义务；未知记号原样透传，round-trip 不破坏。

## 7. 交互投影：left slot / right slot

KRIG 中 mind Note 的界面为**左右双槽**，对照本的字面布局：

- **left slot：文本侧**。承载两个书写面——**语义描述面**（主，note block 编辑器：序列 + h 级别 + rich text）与**图形描述面**（次，可切换：G 层规范条目的直接编辑）。
- **right slot：画布侧**。导图渲染与交互（拖动、折叠、连线、框选、属性检查器）。
- **任一 slot 可全屏**：文本侧全屏 = XMind Outliner 模式；画布侧全屏 = 纯导图模式。tab 式呈现被全屏机制自然吸收。

**同步是持续的，不是切换时的**：左侧改标签 → 画布即变、G 面无涉；画布拖节点 → G 面多一条、语义面零变更；G 面改颜色 → 画布即变、语义面零变更。同步管道带方向标记抑制回环。

**选区同步**：三个面共享"当前选中 id 集"。画布点选节点 → 语义面对应行高亮滚动到位、G 面对应条目高亮；语义面光标所在行 → 画布对应节点高亮。id 是三面之间唯一的 join 键。

**落笔矩阵**（各面操作 → 各层变更，交互层的验收标准）：

| 操作 | S 层 | G 层 | 画布 |
|---|---|---|---|
| 语义面改标签 | 一处 update | 零 | 该节点重绘 |
| 语义面移动缩进块 | parent/order 变更 | 零（布局属性存活） | 子树重排 |
| 语义面键入 `/三角形` | 零（手势消解） | 一条 shape 条目 | 该节点变形 |
| 画布拖动节点 | 零 | 一条 pos 条目 | 即时 |
| 画布新建节点 | 一处插入 | 零（缺省即自动） | 即时 |
| 画布连线 | 一条关系行/三元组 | 零 | 即时 |
| G 面改 color | 零 | 该条目更新 | 该节点重绘 |
| G 面删除 pos 条目 | 零 | 条目消失 | 节点回自动布局 |

**图形描述面跨图种稳定**：v1 flow、v2 bpmn 更换的是语义面文法与画布渲染；G 面永远是 `^id key=value` 属性面——用户学一次全图种通用，实现一次全图种复用。

## 8. 不变量（Phase 0 断言）

- **A1 推导确定性**：同一书写序列推导出同一棵树；级别跳跃按就近父级归属。
- **A2 规范化幂等**：G 层规范形二次序列化字节级不变。
- **A3 双射**：同一张图经任何编辑路径到达，序列化结果一致（S 层为用户代表元，G 层为规范形）。
- **A4 语义编辑最小性**：改一个标签 → 模型 diff 仅一个 update；全部 pos 存活（id 配对，绝不删旧建新）。
- **A5 图形编辑分层落笔**：画布拖动一个节点 → 仅 G 层一条条目变更；S 层零变更。
- **A6 缺省即自动**：画布新建节点 → S 层恰好一处插入，G 层零条目。
- **A7 错误隔离**：S 面坏语法 / G 面坏行均不污染模型，画布保持上一有效状态，错误定位到行。
- **A8 释放语义**：删除一条 G 条目 → 该元素回自动布局，其余一切不变。
- **A9 手势消解**：语义面键入斜杠属性词 → S 层零残留，G 层恰好一条条目。

九条断言即九个 CI 测试用例，先于任何交互代码存在。

## 9. 明确不入模型的（v0 非目标）

贴纸/插画（纯装饰）、甘特与任务信息（项目管理域）、Pitch/ZEN（演示模式）、音频备注（v0 媒体范围外，block 架构留门）、协同编辑、存储。`tree-table` / `matrix` / `timeline` 等结构词表项登记名称、v0 不实现布局算法。

## 10. 画布操作规格（对齐 XMind 肌肉记忆）

约定原则：快捷键与手势**照搬 XMind**（迁移零学习成本）；每个操作的**落笔归属**由本模型分层规则裁定。macOS 记号，Windows 以 Ctrl 对应 Cmd。

### 10.1 创建与结构（落 S 层）

| 操作 | 触发 | 落笔 |
|---|---|---|
| 插入兄弟（其后） | `Enter` | S：一处插入（同父，order+1） |
| 插入兄弟（其前） | `Shift+Enter` | S：一处插入（同父，order-1） |
| 插入子节点 | `Tab` | S：一处插入（选中节点之子） |
| 插入父节点 | `Cmd+Enter` | S：新节点接管选中节点的父位 |
| 新建自由主题 | 双击空白画布 | S：顶层插入 + float；G：pos（双击处坐标） |
| 删除 | `Delete` | S：节点及子树移除；连带清理其 G 条目、悬空 Edge/Span |
| 升降级 | 拖动 / 大纲侧 Tab | S：parent/order 变更（G 层 pos 存活） |

### 10.2 拖动三义分流（本规格核心约定）

| 拖动落点 | 语义 | 落笔 |
|---|---|---|
| 另一节点上 / 兄弟缝隙间 | **改父 / 改序** | S：parent/order 变更 |
| 空白处 | **钉住坐标**（父子不变） | G：一条 pos 条目 |
| `Shift` + 空白处 | **转自由主题** | S：role→float；G：pos |

拖动预览必须在松手前区分三义：缝隙插入高亮（结构）vs 钉住虚影（布局）vs 自由主题标识。对应 XMind 的 drag-reparent / Alt-drag 自由摆位 / Shift-drag 转 floating。

### 10.3 编辑与内容（落 S 层）

| 操作 | 触发 | 落笔 |
|---|---|---|
| 编辑标签 | 双击节点 / `Space` / `F2` | S：content 首段 update。行内编辑器**即 note block 编辑器**——富文本、公式、图片直接可用（对 XMind 的原生超越） |
| 编辑备注 | `F4` / 备注标记点击 | S：content 余部 update（展开完整 block 编辑） |
| 编辑标注 | `F3` | S：labels update |
| 快捷标记 | `Cmd+1…6` | S：markers 优先级 1–6（XMind 同款） |

### 10.4 关系与区间（落 S 层）

| 操作 | 触发 | 落笔 |
|---|---|---|
| 联系线 | `Cmd+L` 后点击目标 | S：一条 Edge。**端点无显式 id 时系统即时生成人类可读 id 并落两面**——"连线自动命名"，不报错拒绝 |
| 边界 | 选中节点后 `Cmd+B` | S：Span(boundary)。选区规范化为最小连续兄弟段；跨分支多选按 XMind 语义拆为多个 Span |
| 概要 | 选中节点后 `Cmd+J` | S：Span(summary) + 结论节点（进入编辑态） |
| 调整区间 | 拖动 Span 框缘 | S：from/to 锚点变更 |

### 10.5 视图与布局（落 G 层或会话）

| 操作 | 触发 | 落笔 |
|---|---|---|
| 折叠/展开 | 节点徽标点击 / `-` `+` | G(V)：collapsed（**持久**） |
| 缩放 | `Cmd+滚轮` / 双指捏合 / `Cmd±` `Cmd+0` | 会话（**视口不持久**） |
| 平移 | `Space+拖动` / 中键拖动 / 双指滑动 | 会话（不持久） |
| 框选 | 空白处左键拖动 | 会话选区（与平移触发互斥：裸拖=框选，Space/中键=平移） |
| 改结构/样式 | 属性检查器（选中后侧栏） | G：structure/color/shape 条目（等价于图形描述面改值） |
| 释放钉住 | 检查器"恢复自动" | G：删除 pos 条目（断言 A8 的画布入口） |

### 10.6 导航与选择（纯会话）

方向键在树上移动选中；`Cmd+Home` 回 root；点选/`Cmd+点选`多选/`Cmd+Shift+A` 选兄弟/`Cmd+Alt+A` 选子级（XMind 同款）。选中 id 集经选区同步（§7）联动三面。

### 10.7 撤销：一条时间线

**S 面、G 面、画布共享同一撤销栈**。`Cmd+Z` 按操作时序回退，不分面——用户不区分"刚才那步落在哪层"。实现约束：同步引擎的每次落笔生成可逆事务，入统一历史；这是双面架构在手感上完整的前提。
