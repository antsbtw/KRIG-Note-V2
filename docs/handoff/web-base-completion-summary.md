## 二、⭐ 刻意**不做**的，以及判据

这部分比做了什么更重要 —— 它防的是「为了整齐而付代价」。

| 不做 | 判据 |
|---|---|
| `poll` / `drainQueue` 留在 renderer | ⭐ **注入脚本里有没有运行时值？** 它们是写死字面量、零参数；且 `poll` **12.5 次/秒**，走 IPC 四跳 **有成本无收益** |
| `element.js` 不走 `web.dom` | ⚠️ 它是**从 Google 现下载的第三方代码**，走 `web.dom` 等于要开 `runDynamic` —— 那是明确拒绝对 renderer 开放的 |
| 不开 `read/query/text/selection` 四个 op | ⚠️ 实查 `WebDom` 接口声明 6 个方法但**全仓零实现**。开出去是**空头承诺**：调了必然失败，而原因是「底座没实现」，排查方向被带偏 |
| `pick()` 退整页找的旧风险 | 改它会**改变提取行为**，要真机逐家验 Gmail/Outlook/QQ/163；收口批次不含行为变更 |
| L3/L5/L6 不建 | ⭐ **现在没有消费者能验证它建对了** —— 那正是 L1 栽的坑（建好了、没人接、消费者被删了） |

⭐ 三处保留的理由**都写在代码注释里**，不是靠文档记着 ——
这样下一个人读代码就知道不是漏掉的。

## 三、⭐⭐ 这一轮真正学到的（按价值排）

### 1. 验证角色必须独立出去

本机写代码 → 推 GitHub → `regression-testing-nj` 上另一个对话**独立注入验证**。

⭐ **五轮复核抓到的全是我自己验不出来的** —— 因为我既写代码又写测试，
会不自觉地按自己的实现思路去断言。抓到的东西层次在往上走：

```
文本断言零区分力 → 假 DOM 不看 selector → 工具说谎 → CSS 语义错 → 修复引入新回归
```

⚠️ 那台机器**能跑单测、不能跑 GUI**（SSH 投不进 Aqua 会话，实测
`screencapture` 报 `could not create image from display`）。GUI 判据只能人在桌面做。

### 2. 别自己实现规范

手写的假 DOM 的 CSS 引擎，**五轮复核五轮出错，且每轮修复又引入新错**。
第五轮那条踩中 **Gmail 真实的 `div[data-message-id] div.ii`** ——
证明不是「边缘差异」。

⭐ 判断：**错全部出在「自己实现 CSS 语义」这一件事上**。
换 jsdom 后那一类整体消失，假 DOM 只留 jsdom 没有的三样
（几何 / 事件留痕 / 求值入口）。

### 3. 日志要打在人看的那块屏上

我在 renderer 加了 `console.warn`，然后请用户给那一行 —— **用户给不了**，
因为它只存在于那个 webview 的 DevTools，而人看的是启动终端。

⭐ 后果：我查了**四轮静态证据**都定不了因，全卡在「拿不到那一行」。
**障碍不在用户，在我把日志放错了进程。**

修法两条：失败在 main 侧也出声；**启动时报一次「登记了什么」**。
⭐ 后者当场排除了一个假说 —— **一行日志顶四轮推断**。

### 4. 「构建通过」证明不了「代码进了产物」

`?raw` 在主进程侧此前零先例。第一次 `electron-forge package` 通过，
但三个标记**都不在 bundle 里** —— 因为还没人 import，被 tree-shake 了。
⭐ 接进 runtime 后才在。**要查的是产物内容，不是构建退出码。**

### 5. 「没有报错」≠「成功」

结账那次日志零条失败 —— 但也**零条 translate 痕迹**。
我没把它当成修好了，而是追问「是真好了还是压根没触发」。
⭐ **先确认那条路径真的走到了。**
