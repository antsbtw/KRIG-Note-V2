# X 模块重建 —— 从零开始

> 分支：`feature/x-module-rebuild`
> 起点：`6234646e`（X 彻底归零，底层原样保留）
> 用户 2026-09-29：「把 x 作为一个非常独立的模块，除了浏览器能力以外，
> 　作为一个很容易装卸的模块才行。」

## 0. 为什么推倒

用户的判断：**「功能看起来很多，但每一个都是很脆弱的。」**

三个当天实测到的证据，都指向同一件事 —— **不是某个 bug，是结构**：

| 症状 | 本质 |
|---|---|
| 删掉 Inbox 界面，底层**一个模块都没掉** | 48 个 IPC 焊在一个 1516 行的 handler 上 |
| `x-pages` 为**两个纯字符串函数**，import 了 596 行的采集模块 | 一根 import 牵住十几个模块（缺口 7 → 11） |
| 代码删了，右栏还显示「x-workbench-view (待 L5 component)」 | **状态残留在别处**（slot 绑定） |

⚠️ 这些**当初都不是故意写成这样的**。所以：
**重写一遍而不定约束，三周后会长回同样的样子。**

## 1. 现在的地基（可信）

```
src/platform/main/web-capability/     6683 行 —— 一行没改
├─ page/    goto · ready · scrollUntil
├─ input/   tap · press · type
├─ net/     载荷捕获（CDP + webRequest 两侧）
├─ dom/     读页面
├─ raw/     原始留痕
├─ trace/   诊断
└─ wiring/  接线（注册表模式）
```

⭐ 它**不 import 任何业务模块** —— 当年那次「分层倒置」
（`import XAnchorResolver` 写进底座）早已改成**注册表**：
业务启动时把自己的表 `push` 进来，底座不认识业务。

⚠️ 但那次是靠**自觉**避开的，`wiring/runtime.ts` 的注释原话：

> 守卫盯的是 Electron 与脚本文本，**不是依赖方向**，所以它只会悄悄烂掉

→ **重建的第一条守卫就该钉这个。**

## 2. ⭐⭐ 重建真正要定的：允许有哪几条线

不是「怎么写」，是「X 和主程序之间允许有哪些连接」。
⭐ **每一条都能写成守卫** —— 这才是「容易装卸」的保证，而不是靠自觉。

草案（待用户拍板）：

**允许**
- `X → web-capability`（用浏览器能力）
- `X → 自己的库表`
- `X 启动时把自己的表 push 给底座`（注册表模式，已验证可行）

**禁止**
- 主程序 `import` X 的任何东西
- X 的视图注册散落在 `renderer/index.tsx`
- X 的 IPC 通道混进全局 `channel-names.ts`
- X 的 repo 混进 `db/` 目录

**形态草案**：X 自带视图、IPC、repo、schema，收进一个目录，
主程序只有**一行**注册它 —— 删 X = 删一个目录 + 删一行。

## 3. ⚠️ 装卸不只是代码

推倒时实测到：删完代码，X 的痕迹仍散在

- slot 绑定（`slotBinding.right` 存着已删视图 id → 右栏残影）
- IPC 通道表 / preload / renderer 注册
- 库表 / schema
- **副作用 import**（`import 'x'` 无 from）—— ⚠️ **tsc 查不出来，只有 vite 运行时才报**，删 X 时栽过一次

→ 新模块要让这些**全部跟着模块走**。

## 5. ⚠️ 重建时必须守住的教训（踩过的，别再踩）

1. **单测证明不了 CDP 通道行为** —— 迁移采集时 1878 条全绿，真机 payloads 直接 0
2. **判据看 `payloads` / `people`，不看推文数** —— 推文有 DOM 兜底撑着，载荷全没时它还有 38 条
3. **别从代码推断运行时行为** —— 为此绕过三个弯全错，每次都是用户一句话挡住
4. **接线不该跟业务逻辑住在一起** —— `registerAnchorTable` 埋在 1516 行 handler 里，不恢复 handler 就全瞎
5. **纯函数不该跟着它碰巧所在的大模块走**
6. **连按钮一起删** —— 留一个点了没反应的壳比没有按钮更糟

```bash
git reset --hard x-before-rebuild   # 第一次推倒前（完整 X）
```
